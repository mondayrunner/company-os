# Acme Studio — the constitution

One rule above everything: **the approval gate.** Anything irreversible or outward — sending a mail, publishing, invoicing, booking, deleting — needs a human to see the final version and say yes. "Do it" on a draft is not permission to send.

## Where a fact lives

One place per fact. Link to it, never copy it.

| Question | Source |
|---|---|
| Prices and packages | `knowledge/pricing.md` |
| Positioning | `knowledge/positioning.md` |
| Goals and boundaries | `compass.md` |
| Company details | `company.md` |
| Status of one account | `accounts/<side>/<id>/STATUS.md` |
| Pipeline, commitments, who holds the ball | `pipeline/pipeline.md` |
| Tasks | `tasks.md` (read through the `tasks` tool) |

## Brain first, then grep

For any question about the company use the company-os tools before searching yourself: `account` (one account), `accounts` (one line each), `canon` (a canonical file), `search`, `tasks`. Talk back through `inbox_post`; the human answers in the inbox.

## Writing

Short, concrete, no filler. Every claim cites a path. "Not found in the brain" is a valid answer; inventing is not.
